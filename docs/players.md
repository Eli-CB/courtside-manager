# The Players tab: js/players.js

Part of the repo's notes: CLAUDE.md says which file covers what and how to keep them current. Read this before changing js/players.js.

- players: Players tab (`#players`, was Free Agents): one table (`topPerformancesCard`) of every NBA stat line of
  a menu of Today / Yesterday (the last game day) / This period (once it has two game days) / Last period (range 'last') / This season (football: Projected first), and for a period or the season a Totals / Per game toggle (`ui.perfPer`; the season per game is `seasonRows`, averages from the Stats used basis, internally range 'avg'); top 300 for the season ranges, 100 otherwise, ranked by value (pickup ideas are only on Plan Ahead);
  search, then one Filters button (`ui.perfFiltOpen`) opening a panel (and the tab's one (i), beside it: `INFO.perf`, kept to what no tip on screen says, short enough for a phone; Per game's line names its stats with no (i) of its own: the owner's ask, Nov 20, 2026): Show toggles (`ui.perfWhose`: me, opp, other, fa, any together, never none; Other teams is also a menu of those teams to pick any number of, the owner's ask: `perfOtherMenu`, `ui.perfOthers`, none picked = all), Lineup All / Active / Bench (`ui.perfSpot`, rostered players only: waivers have no lineup), position and NBA team (each a menu to pick any number from, the owner's ask: `perfMenu`, lists `ui.perfPos` / `ui.perfTeam`, empty = all; a player at any picked position), Rookies, Injured.
